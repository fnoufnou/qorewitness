# Demo site

Static demo site for https://qorewitness.fnoufnou.com. Design rules: `docs/BRAND.md`.

Files on the server:

- `index.html` (this folder)
- `verifier.html`: copy of `web/verifier/dist/index.html` (`pnpm build:verifier`). Its SHA-256 is on the home page. Update the hash after every build.
- `favicon.svg`, `fonts/` (IBM Plex Sans and IBM Plex Mono, SIL Open Font License), `qorewitness-featured.png` (link preview image)
- `sample-clip.mp4` and `sample-receipt.json` (server only, linked from the Prove, jury and developers pages)
- `demo-clip.mp4` and `demo-receipt.json` (old sample, server only, kept so old links keep working)

The sample is one 60-second clip from the test camera of the test computer (CT 262): a test pattern with the text "QoreWitness test camera" and a burned-in clock in Amsterdam time, plus a test tone (H.264 1280x720, AAC). Recorded 24 Nov 2026 08:08:20 to 08:09:20 CET (07:08 UTC) by camera `camera-1`, window 08:00 to 08:10 CET, sealed in block 10,653,907 at 08:10:22 CET (registry v4, receipt v3, spec/3, made by 0.6.0-alpha.3). Original names: `seg_20261124T070820Z.mp4` and `camera-1-1795503600.json`. SHA-256 of the clip: `9e825de8438f30996f768a07a51916296ac59c75648d84148e89160c5d4ec4cb`. QoreWitness Verify shows a green "Original, sealed within 1 minute", with no notes. Check it with:

```bash
pnpm tsx scripts/verify-receipt.ts sample-receipt.json sample-clip.mp4
```

The old sample (`demo-*`, block 10,120,133) now shows an orange result, because its window holds a gap and a late seal.

## New customer pages (preview, 21 Nov 2026)

Pages for the product site are in `web/site/preview/`: `index.html`, `how-it-works.html`, `get-started.html`, `cameras.html`, `daily-use.html`, `prove.html`, `plans.html`, `faq.html`, `trust.html`, `developers.html`. Shared files: `assets/site.css`, `assets/site.js`, `fonts/`. The site is live. Old `/preview/*.html` links are redirect stubs. `node scripts/build-site-preview.mjs` writes a noindex draft to `web/site-draft/`. Check links with `node scripts/check-site-links.mjs`.

- The pages are generated by `node scripts/build-site-preview.mjs`. Copy and facts are in that script. Edit it and run it again. Do not edit the HTML by hand.
- Deploy: copy the whole `web/site/` folder as before, including `assets/` and `preview/`. Review at `https://qorewitness.fnoufnou.com/preview/`.
- Go live: run `node scripts/build-site-preview.mjs --live`. This writes the pages to `web/site/`, REPLACES `index.html`, and removes the noindex tag. Keep a copy of the old `index.html` first. The old roadmap and status text are not carried over.
- Hero photos: drop `hero-frames.jpg` (large frame, about 16:10, at least 1200 px wide), `hero-frame-2.jpg` and `hero-frame-3.jpg` (small frames, 16:11, at least 600 px wide) in `web/site/assets/`. They are CSS background images in `site.css`. No rebuild is needed. Until they exist, a dark gradient placeholder shows.
- Open placeholders: every "Screenshot:" box on `get-started.html`, `daily-use.html` and `prove.html` is filled after the real test on 24 Nov. Update the Tapo C210 row on `cameras.html` after that test.
- Check before going live: `install.sh` must be served at `https://qorewitness.fnoufnou.com/install.sh`.
