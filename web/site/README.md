# QoreWitness website

The live site at https://qorewitness.fnoufnou.com. Design rules: `docs/BRAND.md`.

## How the pages are made

- All pages are generated by `node scripts/build-site-preview.mjs --live`. Copy and facts live in that script. Edit it and run it again. Do not edit the HTML by hand.
- Without `--live`, the script writes a noindex draft to `web/site-draft/` for review.
- Shared files: `assets/site.css`, `assets/site.js`, `assets/screens/` (real app screenshots, WebP), the hero photos in `assets/`, and `fonts/` (IBM Plex, SIL Open Font License).
- `preview/*.html` are redirect stubs for old shared links (noindex, each points to the current page).
- Check every internal link and anchor: `node scripts/check-site-links.mjs`.

## QoreWitness Verify

- `verifier.html` is a copy of `web/verifier/dist/index.html`. Build it with `pnpm build:verifier` (reproducible). The generator copies it in.
- After every build, set `VERIFIER_SHA` in `scripts/build-site-preview.mjs` to the SHA-256 of the new file and regenerate, so the Developers and jury pages show the right fingerprint. Deploy `verifier.html` and those pages together.

## Install line

The site shows one install line that runs `install.sh` from a release tag on raw.githubusercontent.com, and the "read the script first" link points to the same tag (`TAG` in the generator). The site does not need to serve its own `install.sh`. If it does, keep it identical to the tagged file.
