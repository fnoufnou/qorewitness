Try it with the demo clip

The demo clip is a generated test pattern. Download both files and drop them on the verifier. Then use its button to change one byte and check again. The result turns red.

Demo clipDemo receipt

What a green result means

  • The file existed at the time of the public record.
  • It has not changed since it was sealed.
  • One known camera made the seal.

What it does not mean

  • That the scene was real. A staged scene is sealed the same way.
  • That a court will accept it. A court weighs it as ordinary evidence.
