Detailed Findings

ETH-001 Potential Window Overlap Vulnerability
HIGH
Category
Logic Flaws
Description
The _checkWindow function uses nextWindowStart[msg.sender][w.deviceId] to determine the earliest allowed window start time. However, if a device is revoked and then re-registered, the nextWindowStart may not be reset properly, potentially allowing overlapping windows.
Location
AnchorRegistry.sol:270
Impact
An attacker could potentially submit overlapping windows for a device that was previously revoked and re-registered, leading to invalid state transitions.
Recommendation
Add explicit reset logic for nextWindowStart when a device is revoked and ensure proper initialization upon re-registration.
Severity HIGH
Status Open
